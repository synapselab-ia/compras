# Compras

Sistema em desenvolvimento para organizar fluxos de contratações públicas, centralizar o acompanhamento operacional, reduzir controles fragmentados e apoiar pesquisa de preços em fontes públicas.

## Estado atual

O projeto está na fase `Foundation-00 — Public Bootstrap`.

Ainda não existe aplicação funcional, banco conectado ou ambiente com dados reais. O repositório está público nesta fase e, por isso, somente documentação sanitizada e dados fictícios podem ser versionados.

## Princípio central

O GitHub é a fonte canônica do produto e do desenvolvimento. Conversas com IA são sessões temporárias de trabalho e não substituem o estado documentado no repositório.

## Continuidade por IA

Uma nova sessão deve começar por `AGENTS.md` e `docs/00-START-HERE.md`.

Comando de continuação pretendido:

> Continue o projeto `synapselab-ia/compras` pelo protocolo canônico e execute a `NEXT_ACTION`.
